# Задача 015: проверка источников библиотеки перед скачиванием

## Зачем

Манифест `evaluation/library/manifest.json` описывает два комплекта книг.
У трёх книг статус `check`: адрес или формат не подтверждены. Скачивание
делает владелец; до этого нужно знать, что по адресу лежит именно то,
что записано, и в каком виде.

## Что проверить (сеть — только чтение, файлы не сохранять)

1. **en-anchor-mml** — `https://mml-book.github.io/book/mml-book.pdf`:
   отвечает ли адрес (HEAD или первые байты), размер, `%PDF-` в начале,
   дата/версия на странице книги; условия использования дословно
   (не больше одной короткой цитаты).
2. **ru-ml-sokolov** — `esokolov/ml-course-hse`, каталог
   `2019-fall/lecture-notes` через GitHub API (`/repos/.../contents/...`):
   список файлов; есть ли PDF к каждой лекции или только `.tex`;
   общий список тем. Если PDF нет — есть ли PDF той же редакции
   в другом месте репозитория.
3. **ru-la-gelfand** — `https://mccme.ru/free-books/linalg/gelfand.pdf`:
   размер, `%PDF-`; по первым ~200 КБ (Range-запрос, в память) —
   есть ли текстовые операторы (`BT`/`Tj`/`TJ`) и шрифты или только
   изображения (признак скана). Вывод: «текстовый слой вероятен / скан
   вероятен / нельзя установить».
4. Для всех книг со статусом `ready` — ответ HEAD (код, размер,
   `Content-Type`). Сломанные адреса — в отчёт.

## Результат

`tasks/015-report.md`: по каждой книге — адрес, код ответа, размер,
вывод и предлагаемое изменение манифеста (статус, адрес, заметка).
Манифест не правь.

## Правила

Сеть — только чтение, ничего не сохранять на диск, кроме отчёта и
заметок. Экономия контекста — AGENTS.md. Цитаты — не больше одной
короткой на источник.

## Можно менять

- `tasks/015-report.md` (новый)

## Критерий приёмки

Для каждой из 9 книг — код ответа и размер; для трёх книг `check` —
вывод с основанием.
