### Найденные ограничения (первый этап)

- У МЦНМО проверена [расшифровка C0–C3](https://mccme.ru/free-books/#cpr). C2 разрешает просмотр и печать, но требует отдельного разрешения для коммерческого использования; C1 разрешает распространение только неизменённого текста. Поэтому такие книги нельзя автоматически считать свободным корпусом для RAG/обучения.
- На [официальной странице Axler](https://linear.axler.net/) четвёртое издание имеет CC BY-NC; перечислены английский, китайский, фарси, греческий, иврит и португальский. Русский перевод открытого четвёртого издания на этой странице не указан.
- GitHub API не определил лицензию `esokolov/ml-course-hse` и `yandexdataschool/ML-Handbook`. Проверка файлов продолжается; отсутствие значения в API не является окончательной проверкой лицензии.

Под «исследованием» ниже понимается именно создание корпуса, извлечение фрагментов и подготовка обучающих данных, а не простое чтение книги.
