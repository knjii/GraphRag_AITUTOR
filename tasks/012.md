# Задача 012: два комплекта источников для теста — RU и EN

## Зачем

Нужен полноценный тест graph-RAG и RL на **библиотеке** связанных книг,
а не на одной. Каждый комплект — четыре полноценных источника
(**не брошюры**, ориентир 150–800 страниц):

1. машинное обучение;
2. обучение с подкреплением;
3. линейная алгебра;
4. теория вероятностей.

Темы выбраны так, чтобы между книгами были настоящие связи: ML опирается
на линейную алгебру и вероятность, RL — на вероятность (марковские
процессы, матожидания) и ML. Текущая книга — русский перевод
Deisenroth, Faisal, Ong «Mathematics for Machine Learning» (MML) — остаётся
в корпусе, новые книги должны с ней пересекаться.

**Приоритет владельца:** качество теста важнее возможности публикации.
Лицензию выясняем обязательно, но закрытая лицензия не исключает книгу
из внутреннего теста — она лишь помечается.

## Критерии (в порядке важности)

1. Полноценный учебник или курс лекций с формулами, определениями,
   теоремами; уровень бакалавриат–магистратура; сравнимый с MML.
2. Пересечение тем с MML и с другими книгами комплекта (для межкнижных
   вопросов).
3. Доступность текста: текстовый PDF, HTML или LaTeX-исходники
   (исходники — лучший вариант: формулы без распознавания). Сканы —
   хуже.
4. Для RU: **русский оригинал** предпочтительнее перевода.
5. Лицензия и возможность публиковать результаты (метрики, примеры
   вопросов, фрагменты).

## Что сделать

Для каждого кандидата (не меньше 3 на ячейку «язык × тема», итого ≥24):
- точное название, авторы, издание, год, страницы;
- ссылка на официальную страницу и на текст (PDF/HTML/исходники);
- формат: текстовый PDF / HTML / LaTeX / скан — по описанию или
  метаданным (размер файла, наличие исходников в репозитории);
- лицензия с цитатой условий; «неясно», если не нашёл;
- оценка пересечения с MML и с остальными темами (по оглавлению);
- оценка 1–5 по критериям 1–4 и отдельно по 5.

Итог: **рекомендованный комплект RU и комплект EN** (по одной книге на
тему) плюс по одному запасному, с обоснованием. Отдельно — что из
выбранного можно публиковать и в каком объёме.

## Ограничения

- Не скачивай книги целиком. Разрешено: страницы описания, оглавления,
  лицензии, README, API метаданных (в т. ч. HEAD-запрос размера файла).
- Правила экономии контекста из AGENTS.md: заметки по каждому кандидату
  сразу в отчёт, выводы команд — только нужные куски.
- Материалы, собранные в задаче 007 (`tasks/007-report.md`), используй,
  не повторяй проверку.

## Формат результата

`tasks/012-report.md`, пиши по ходу: таблица кандидатов по ячейкам,
карточки, два рекомендованных комплекта, запасные, раздел о публикации.
