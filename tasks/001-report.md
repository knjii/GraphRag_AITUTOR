# Отчёт по задаче 001

## Что сделано

- `scripts/inspect_cell.py`: добавлена `inspect(path, *, expected, max_empty_share)`, возвращающая список проблем. Сводка для читаемого файла сохранена в прежнем формате. Обрабатываются ошибки чтения, декодирования UTF-8 и JSON, отсутствие ответов, несовпадение ожидаемого количества, превышение доли пустых ответов и отсутствие модели ответа. `main(argv=None)` принимает один или несколько файлов и оба параметра проверки, печатает проблемы через `; ` с префиксом `   НЕГОДЕН: ` и возвращает 1 при любой браковке. Проверка остальных файлов продолжается.
- `tests/test_inspect_cell.py`: добавлены 18 тестовых случаев. Скрипт импортируется через `importlib` по пути, входные файлы создаются через `tmp_path`.
