# Задача 003: обзор литературы — Graph-RAG, 2024–2026

## Зачем

Проект — RAG по русскоязычным учебникам математики (формулы в LaTeX,
определения, теоремы, связи между понятиями). Граф знаний строится
LLM-извлечением сущностей и связей (Neo4j), поиск — гибрид Qdrant (dense
bge-m3 + BM25) + графовый канал + реранкер. Уже измерено:

- граф даёт recall@16 +0.018 (значимо), весь выигрыш — за 8-м местом;
- фильтры графа (порог хабов, вес редкости) эффекта не дают;
- 56 из 100 промахов связывающих вопросов — нужного фрагмента нет даже
  в пуле кандидатов;
- на MultiHop-RAG граф даёт +0.079 recall@16, на втором шаге обхода
  граф 0.500 против 0.074 у векторного поиска.

Нужно выбрать архитектуру graph-RAG, наиболее подходящую именно нам,
опираясь на современные работы.

## Что сделать

Веб-поиск по авторитетным источникам: arxiv.org, aclanthology.org,
openreview.net, proceedings (NeurIPS, ICLR, ACL, EMNLP, SIGIR, KDD, WWW),
Semantic Scholar, Scopus-индексируемые журналы, GitHub. Найди и прочитай
(как минимум аннотацию и эксперименты) **не меньше 15** работ 2024–2026.

Обязательно проверь: GraphRAG (Microsoft, local/global), LazyGraphRAG,
LightRAG, HippoRAG и HippoRAG 2, Think-on-Graph и ToG-2, G-Retriever,
GFM-RAG, PathRAG, KAG, MiniRAG, NodeRAG, StructRAG, RAPTOR (иерархическая
альтернатива графу), а также обзоры и бенчмарки 2025–2026 о том, **когда
граф действительно помогает** (сравнения RAG и GraphRAG, GraphRAG-бенчмарки).
Отдельно поищи работы по структурам для **математических текстов**:
зависимости определений и теорем, math-aware retrieval, поиск формул.

Для каждой работы:
- точное название, первый автор et al., год, площадка, **ссылка**
  (arXiv ID, если есть);
- как строится граф (узлы, рёбра, чем извлекается, стоимость построения);
- как идёт поиск (затравки → обход → ранжирование: PPR, сводки сообществ,
  пути, GNN и т. п.);
- данные и цифры против обычного RAG (с номером таблицы);
- открытый код, лицензия, живость репозитория;
- применимость к нам (1–5) и почему: русский язык, 1–2 тыс. фрагментов,
  одна RTX 3090, локальные модели 4–9B.

## Формат результата

`tasks/003-report.md`:
1. Сводная таблица работ.
2. Карточки по каждой работе.
3. Три архитектуры-кандидата для нас: обоснование, риски, ожидаемый эффект,
   что из литературы объясняет наши замеры (выигрыш только за 8-м местом,
   промахи «нет в пуле»).
4. Список источников со ссылками.

**Не выдумывай.** Не смог открыть или проверить — пиши «не проверено».
Цифры — только из текста работы.
