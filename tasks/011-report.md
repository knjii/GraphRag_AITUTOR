## Протокол итогового запуска

- Затравки: k=3 из заголовка слепка; положительный score фрагмента, вес лексической сущности 1. Названия и вопрос лемматизируются существующими tokenize/lemmatize_token, совпадение целой последовательности слов. Все 388 вопросов получили сущности; вопросов без затравок нет. 42 вхождения passage-затравок отсутствуют в восстановленном графе: они сохраняются как изолированные узлы, масса возвращается в распределение затравок.
- alpha — вероятность возврата; L1 tolerance=1e-10, максимум 200 итераций; несходимость прерывает расчёт. Основной перебор без IDF. Вероятности сортируются по убыванию, равенства разрешаются по ID; затравочные фрагменты исключаются.
- Известный первый фрагмент: существующие linked_pairs и summarize, 185 пар / 370 направлений. Как в существующем коде, медиана — верхний центральный ранг среди достижимых; MRR для недостижимых использует 1/NOT_FOUND. В этот протокол входят пары, оба фрагмента которых есть в восстановленном графе.
- Уровень вопроса: recall@30 — средняя по вопросам доля найденных эталонов; precision@30 — среднее число найденных эталонов / 30 (включая неполную выдачу). Текущий graph берётся непосредственно из слепка, ранги обрезаются на 30. «Только из графа» — сумма найденных пар (вопрос, эталонный фрагмент), отсутствующих во всём канале base; всего таких пар 91. Один фрагмент в разных вопросах считается отдельно.
- Разницы — PPR минус текущий graph. Использован существующий paired_bootstrap: 10000 выборок вопросов, seed=20260815, 95% CI. Для graph_only_found бутстрап считает разницу среднего количества на вопрос; в итоговой таблице CI дополнительно пересчитан на сумму умножением на 388.
- Лучший вариант выбирается сначала по graph_only_found, затем по recall@30. Выбор на тех же вопросах, доверительные интервалы без поправки на 12 вариантов. Это офлайн-отбор кандидата, не подтверждение серверного улучшения.

## Решение и ограничения

По критерию задачи: PPR — кандидат на серверную проверку в спринте 2. Лучший вариант alpha=0.3, entity_weight=1.0: «только из графа» 44 против 41; recall@30 25.515% против 23.454%.

Проверка с известным первым фрагментом и проверка вопроса измеряют разные режимы: вопрос также даёт лексические сущности и несколько passage-затравок. Нельзя переносить вывод одного режима на другой. Восстановление неполное (47 cache misses), а лексические затравки — приближение HippoRAG 2. Выбранный вариант оценивался на данных подбора; независимого подтверждения нет.

Обязательные пункты выполнены. Опциональный вариант затравок по embedding-близости не реализован; IDF реализован и покрыт тестами, но отдельный замер с ним не проводился. Серверная проверка не проводилась. Новых пакетов, сетевых запросов и коммитов нет. Чужие файлы и запрещённые каталоги не изменялись.

У выбранного варианта при известном первом фрагменте MRR ниже текущего (0.1111 против 0.1600), hit@30 выше (0.7432 против 0.7216).
