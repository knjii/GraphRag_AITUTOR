## 5. Готовность к RL

| что нужно | есть | чего не хватает | объём |
|---|---|---|---|
| среда для генератора | `eval answers --from-trace`, `answer_from_context` | обёртка «вопрос + контекст → промпт» для тренера (TRL/Unsloth) | 1–2 дня |
| среда для отбора | `replay` по слепку | интерфейс действия «выбрать k из пула», награда за прирост | 2–3 дня |
| быстрая награда | функции раздела 3 | составная награда, `R_precision`, формульная v2 с эквивалентностью, тесты на взлом | 3–4 дня |
| данные для обучения | — | вторая книга и больше, генерация вопросов, приёмка M4 | зависит от лицензий (задача 007) |
| логирование | `observability/`, сохранение ответов | метрики по шагам обучения, выборка генераций на каждом шаге | 1 день |

## 6. Технический долг, мешающий опытам с графом

- Нет PPR и узлов-фрагментов в графе: схема HippoRAG 2 требует переделки хранилища и извлечения.
- Слепок фиксирует пул только при старых настройках: `align_to_snapshot` (`evaluation/trace.py:270`) запрещает менять настройки обхода. Каждая новая схема графа требует нового слепка на сервере.
- Подробный разбор связности модулей и покрытия тестами не выполнен — это остаток задачи, его можно продолжить в сессии Codex после сброса лимита.
