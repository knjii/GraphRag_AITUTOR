# Задача 014: сверка стека обучения GRPO по первоисточникам

## Зачем

`scripts/train_grpo.py` написан без установленных TRL, Unsloth и vLLM
(на ноутбуке их нет, GPU нет). Аренда карты стоит денег: если в день
аренды скрипт упадёт на несуществующем поле или молча обрежет промпт,
день потерян. Нужно заранее сверить каждый вызов с **актуальными на
сегодня** версиями по исходному коду и документации.

## Что проверить

Для каждого пункта — версия, ссылка на строку исходного кода (GitHub,
тег релиза) или раздел документации, вывод «совпадает / расходится /
нельзя установить».

1. **TRL, последняя версия на PyPI.** `GRPOConfig`:
   - существуют ли `loss_type="dr_grpo"`, `scale_rewards` (тип: bool или
     строка?), `use_vllm`, `max_prompt_length`, `max_completion_length`,
     `num_generations`, `beta`, `temperature`;
   - **значение `max_prompt_length` по умолчанию** и как именно
     обрезается промпт (слева/справа);
   - ограничение на `per_device_train_batch_size` × число процессов
     относительно `num_generations` (кратность).
2. **Функция награды в TRL**: какие именованные аргументы получает —
   колонки набора (`context`, `reference`, `gold_in_context`,
   `question`, `question_id`), `completion_ids`, `prompts`, что-то ещё;
   в каком виде приходят `completions`, если `prompt` — **строка**
   (не список сообщений).
3. **Строковый промпт.** Скрипт собирает промпт сам через
   `tokenizer.apply_chat_template(..., enable_thinking=False)` и отдаёт
   строкой. Не применит ли TRL шаблон чата повторно? Добавляет ли
   спецтокены (BOS) второй раз?
4. **Qwen3.5-4B**: принимает ли шаблон чата `enable_thinking`; как
   иначе гасится размышление (карточка модели на Hugging Face).
5. **Unsloth**: поддержка GRPO для Qwen3.5 (версия, дата), совместимость
   `FastLanguageModel.from_pretrained(..., fast_inference=True,
   max_lora_rank=...)` с текущей версией; какую версию vLLM требует.
   Есть ли у Qwen3.5 в Unsloth ограничения (гибридное внимание, mamba-слои
   и т. п.) для `fast_inference`.
6. **vLLM**: поддержка архитектуры Qwen3.5 и минимальная версия.
7. **Память.** Найти опубликованные замеры GRPO + LoRA для моделей
   3–5 млрд параметров с промптом 8–12 тыс. токенов на карте 24–48 ГБ
   (блоги Unsloth, issue, статьи). Не оценивать самому — только
   найденные цифры со ссылками.
