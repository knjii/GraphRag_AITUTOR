# Передача задачи разработчику (Codex)

Роли: Claude — исследователь и приёмщик, Codex — разработчик. Codex работает
в рабочей копии `C:\python\rag_textbook-codex` на ветке `agents/dev`.
Человек вливает `agents/dev` в `develop/graph_rag` после приёмки.

## Цикл

1. Написать `tasks/NNN.md` в рабочей копии: зачем, что сделать, «Можно
   менять» (список файлов), критерий приёмки. Правила разработчика —
   в `AGENTS.md`.
2. Запустить (PowerShell):
   `C:\python\rag_textbook-codex\scripts\codex_task.ps1 -Task NNN`
   Скрипт останавливается, если модель не `gpt-6-astra` или рассуждение
   не `medium`. Человек может следить вживую: `scripts\codex_watch.ps1`.
3. Проверить **самому**, отчёту не верить:
   - `git -C C:\python\rag_textbook-codex diff` и новые файлы;
   - тесты и `ruff` интерпретатором `C:\python\rag_textbook\.venv\Scripts\python.exe`;
   - живые данные, если задача их касается;
   - изменены ли только разрешённые файлы.
4. Вердикт в `tasks/NNN-review.md`: «вернуть» с пронумерованными замечаниями
   (тогда `codex_task.ps1 -Task NNN -Review`) или «ПРИНЯТО».
5. Не больше трёх возвратов — дальше решение за человеком.
6. Коммит и слияние делает человек.
